# フェーズ10: ワールド拡張(拡張)

## 目的

フェーズ9の3DワールドをRobloxタイクーンらしい「場所」に育てる。
DOMパネルに残っていた図鑑・転生をワールド内の施設として体験させ、
手動タップをコイン山の回収に置き換える。

## 仕様の要点

- **飼育場**: 柵付きエリア。捕獲済みの豚(種類ごとに1匹)が中を歩き回る。
  入口の看板に近づくと図鑑オーバーレイがビューポート内に表示される
- **転生の祠**: 金の豚像。近づくと周回コイン・獲得予定メダルが表示され、Eキーで転生(確認あり)
- **コイン山**: フィールドにランダム出現し、キャラクター接触で回収
  (現在レート×8秒分)。回収から20秒後に別の場所へ再出現。ヘッダーのタップボタンは廃止
- **ワールド拡大**: 20×12 → 28×18。木・池・岩・花・干し草ロールの装飾を追加

## 実装方針

- コイン山の数値(回収秒数・再出現間隔)は constants.ts に集約し、ロジックのテストを書く
- コイン山の状態は一時状態(TransientState)とし、**セーブスキーマは変更しない**
  (persistのversionは上げない)
- 飼育場の豚の徘徊はUI層の演出(sin/cosの揺らぎ)とし、ロジックには入れない
- オーバーレイ(図鑑・転生)は近接している間だけ表示し、離れると自動で閉じる

## 完了条件(Definition of Done)

- [ ] コイン山の出現・回収・再出現がロジックのユニットテストで担保されている
- [ ] 飼育場に捕獲済みの豚だけが表示される
- [ ] 図鑑・転生がワールド内の近接インタラクションで操作できる(DOM下部のパネルは撤去)
- [ ] 全ユニットテストが通過し、`npm run build` が成功する
