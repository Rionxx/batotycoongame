# フェーズ7: プレステージ(拡張)

## 目的

施設が最大レベルに達した後の目標欠如(known-issues記載)を解消する。
進行をリセットする代わりに恒久ボーナスを与え、周回ごとに立ち上がりが速くなる
放置ゲームの定番ループを導入する。

## 前提条件

フェーズ6(実績)が完了していること(転生関連の実績を追加するため)。

## 進め方

1. `master` から `phase/7-prestige` ブランチを作成する
2. `docs/requirements.md` に転生の仕様(リセット範囲・メダル計算式・解放条件)を追記する
3. メダル計算・転生後状態の生成を `src/logic/prestige.ts` に純粋関数で実装し、テストを同梱する
4. ストアに転生状態を追加する。**persistのversionを上げてmigrateを実装する**
5. 転生パネル(獲得予定メダル・確認ダイアログ)を実装する
6. `docs/balance-notes.md` にメダル計算式の根拠を追記する

## 設計方針

- **リセットする**: コイン・累計コイン(周回内)・施設レベル・出現中の豚
- **引き継ぐ**: 豚図鑑(長期メタ要素)・実績・メダル・転生回数
- メダルボーナスはレート計算式の末尾に乗算で加える(既存の式の構造を変えない)
- 転生は取り返しがつかない操作なので、確認ダイアログで獲得予定メダルを明示する

## 完了条件(Definition of Done)

- [ ] メダル計算・リセット範囲のユニットテストが通過している
- [ ] 旧セーブからのmigrateテストがある
- [ ] 転生前後でレート・図鑑・実績が仕様どおり変化することをテストで確認した
- [ ] メダル計算式の根拠が balance-notes.md に記録されている
