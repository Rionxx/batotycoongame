# フェーズ6: 実績システム(拡張)

## 目的

プレイヤーの進行に節目と目標を与える。図鑑(豚)が「収集の実績」を担っているため、
本フェーズの実績は「進行の実績」(累計コイン・施設強化・捕獲回数など)に焦点を当てる。

## 前提条件

フェーズ1〜5(MVP)が完了していること。

## 進め方

1. `master` から `phase/6-achievements` ブランチを作成する
2. `docs/requirements.md` に実績の仕様(一覧・条件・報酬の有無)を追記する
3. 実績定義を `src/logic/constants.ts` に、判定ロジックを `src/logic/achievements.ts` に実装する
   - 条件は宣言的に(種別+しきい値)定義し、判定は純粋関数 `evaluateAchievements(state)` に集約する
   - ユニットテストを同じコミットで追加する
4. ストアに実績状態を追加する。**persistのversionを上げ、旧セーブからのmigrateを必ず実装する**
5. 実績パネルと解除トーストのUIを実装する
6. `docs/manual-test-checklist.md` に確認手順を追記する

## 設計方針

- 実績は**バッジのみ(ゲームプレイ上の報酬なし)**を基本とする。レート等に影響させると
  フェーズ5のバランスが崩れるため。報酬を付ける場合はバランスノートの更新とセットで行う
- 実績の解除は不可逆(一度解除したらリセット以外で取り消さない)
- 将来のフェーズ(プレステージ等)が実績種別を追加できるよう、条件種別はunion型で拡張可能にする

## 完了条件(Definition of Done)

- [ ] 実績の一覧・条件が requirements.md に記載されている
- [ ] 判定ロジックにユニットテストがあり全て通過している
- [ ] 旧バージョンのセーブデータを読み込んでも壊れない(migrateのテストがある)
- [ ] 実績パネルで解除済み/未解除が確認できる
