# フェーズ11: モバイル対応(拡張)

## 目的

フェーズ9〜10の3Dワールドはキーボード操作専用で、スマホでは移動できない
(known-issues記載)。PC・スマホの双方で同じ体験を成立させる。

## 仕様の要点

- **移動**: 画面左下のバーチャルスティック(ドラッグ量に応じた可変速)。
  キーボード(WASD/矢印)と併存し、どちらでも操作できる
- **インタラクト**: 施設・祠に近づいたとき、画面右下に丸いアクションボタンを表示。
  タップでEキーと同じ処理(強化/転生)を行う
- **図鑑オーバーレイ**: 縦画面では全幅表示にし、閉じるボタンを設ける
- **レイアウト**: 縦画面でビューポート高さを確保し、HUDの文字量を減らす

## 実装方針

- 入力は**純粋関数に切り出してテストする**(`resolveMoveVector`)。
  キーボードのSetとスティックのベクトルを合成し、長さ1にクランプする
- スティックの状態は毎フレーム参照するためReact stateに置かない(refで共有)
- タッチ操作の可否は `pointer: coarse` メディアクエリで判定する。
  PCでは表示しない(タッチ対応PCではキーボードと併用できるよう、判定はUI表示のみに使う)
- Canvasは `touch-action: none` を指定し、操作中のページスクロールを止める
- ロジック層・ストア層は変更しない
