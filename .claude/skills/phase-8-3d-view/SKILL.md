# フェーズ8: 3D化(拡張)

## 目的

牧場ビュー(豚の出現・捕獲)をReact Three Fiberで3D化する。
フェーズ2以来守ってきた「ロジックはUIフレームワーク非依存」の分離を実証する
フェーズでもある。**ロジック層・ストア層の変更は行わない。**

## 前提条件

フェーズ7までが完了していること。

## 進め方

1. `master` から `phase/8-3d-view` ブランチを作成する
2. `three` と `@react-three/fiber` を導入する(React 18系に対応するfiber v8を使う)
3. `src/components/three/` 配下に3Dシーンを実装する
   - 牧場の地面・環境(ローポリ・プリミティブ中心。外部3Dモデルのアセット調達はしない)
   - 出現中の豚(ストアの `activePig` の相対座標を3D空間にマッピング、クリックで捕獲)
   - レア度に応じた見た目の差(色・エフェクト)
4. 既存の2D牧場(`PigField`)を3D版に差し替える。図鑑・施設などの周辺UIはDOMのまま残す
5. `npm run build` とバンドルサイズを確認し、`docs/manual-test-checklist.md` に3Dの確認手順を追記する

## 設計方針

- 3Dはあくまで「見た目の差し替え」。座標(0〜1の相対値)や出現・捕獲の判定はロジック層の
  既存実装をそのまま使う
- WebGL非対応環境へのフォールバックは今回のスコープ外(known-issuesに記録する)
- カメラは固定または軽い自動旋回に留め、操作説明が必要な自由カメラは導入しない

## 完了条件(Definition of Done)

- [ ] 3D牧場で豚の出現・捕獲が一通り動作する
- [ ] ロジック層(`src/logic/`)・ストア層に変更がない(diffで確認)
- [ ] 全ユニットテストが通過し、`npm run build` が成功する
- [ ] 既知の制限(WebGLフォールバック等)が known-issues.md に記録されている
