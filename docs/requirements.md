# 要件定義

2Dタイクーンゲーム(豚牧場テーマ)のMVP要件。本ドキュメントはフェーズ2以降の
型設計・ロジック実装・UI実装の唯一の仕様ソースとする。

## ゲームの骨格

- プレイヤーは豚牧場のオーナー。コインが自動的に貯まり、コインで施設を強化し、
  牧場に現れる豚を捕獲してコレクションする
- コアループ: **コインが貯まる → 施設を強化して生成レートを上げる → 豚が出やすくなる/生成がさらに加速する → 豚コレクションが埋まる**

## 資源

資源は**コイン1種類のみ**とする(複数資源はスコープ外)。

| 項目 | 値 |
|---|---|
| 資源の種類 | コインのみ |
| 基本自動生成レート | 1 コイン/秒(施設レベル0の状態) |
| 手動収集 | ~~画面タップ +1~~ → フェーズ10でコイン山の接触回収に置き換え(下記) |
| tick間隔 | 1秒(内部計算は1秒単位。UI表示は補間してよい) |

### レート計算式

```
生成レート(コイン/秒) = (基本レート 1 + えさ場の加算 + 豚小屋の加算) × 市場の倍率 × 豚コレクションボーナス
```

### オフライン収集

- **上限あり方式**を採用: 最終プレイ時刻からの経過時間ぶんを一括加算するが、**最大2時間分**まで
- 復帰時に「オフラインで N コイン獲得」をモーダル表示する
- オフライン中、豚は出現しない(捕獲操作が必要なため)

## 施設一覧

施設は4種類。各施設は個別にレベルを持ち、レベル1上げるごとに効果が線形加算(倍率系は乗算的に累積)される。

| 施設名 | 効果(1レベルあたり) | 初期コスト | コスト成長率 | 最大レベル |
|---|---|---|---|---|
| えさ場 | コイン生成 +1/秒 | 10 | ×1.15 | 100 |
| 豚小屋 | コイン生成 +5/秒 | 100 | ×1.15 | 100 |
| 市場 | 全生成レート ×(1 + 0.10×Lv) | 500 | ×1.25 | 50 |
| 看板 | 豚の出現率 +5%(加算) | 250 | ×1.20 | 12 |

### コスト計算式

```
レベル n → n+1 のコスト = floor(初期コスト × 成長率^n)
```

- 例: えさ場 Lv0→1 は 10、Lv1→2 は 11、Lv10→11 は 40
- コストが足りない場合、購入ボタンは非活性にする(借金なし)

## 豚の収集ルール

### 出現と捕獲

- **30秒ごと**に出現判定を行う(画面がアクティブな間のみ)
- 出現確率: **基本20% + 看板レベル×5%**(上限80%)
- 出現した豚は画面内をうろつき、**15秒以内にタップすると捕獲**。タップしなければ消える
- 同時に出現する豚は1匹まで

### 種類とレア度

図鑑は**全12種**。レア度は3段階で、出現時に以下の確率で抽選される。

| レア度 | 種類数 | 出現時の抽選確率 | 1匹あたりの生成ボーナス |
|---|---|---|---|
| コモン | 6種 | 70% | +1% |
| レア | 4種 | 25% | +3% |
| エピック | 2種 | 5% | +10% |

- レア度内のどの種になるかは均等抽選
- **重複して捕獲した場合**はコインに変換される(コモン: 現在レートの30秒分、レア: 2分分、エピック: 10分分)

### 収集の見返り

- 図鑑に登録された豚1匹ごとに上記の生成ボーナスが**恒久的に加算**される
  (全12種コンプリートで +1%×6 + 3%×4 + 10%×2 = **+38%**)
- 豚コレクションボーナスはレート計算式の末尾に `×(1 + 合計ボーナス)` として乗る
- コンプリート時は達成モーダルを1回表示する(それ以上の報酬はスコープ外)

## セーブ

- `localStorage` に自動保存(Zustand persist)。保存タイミングは状態変更ごと
- セーブスロットは1つ。リセット機能(全消去)を設定画面に置く

## 実績システム(フェーズ6で追加)

- 実績は**バッジのみ**でゲームプレイ上の報酬はない(フェーズ5のバランスを崩さないため)
- 解除は不可逆。データリセットでのみ初期化される
- 条件は「種別+しきい値」の宣言的定義とし、判定は1秒tickで行う(解除表示に最大1秒の遅延を許容)
- 旧セーブデータの読み込み時は、その時点で条件を満たしている実績を**通知なしで解除済み**にする

| ID | 名称 | 条件 |
|---|---|---|
| firstCoins | はじめてのおこづかい | 累計コイン 100 |
| rich1 | 小金持ち | 累計コイン 10,000 |
| rich2 | 豚舎の大富豪 | 累計コイン 1,000,000 |
| firstUpgrade | はじめての強化 | 施設レベル合計 1 |
| builder | 拡張工事中 | 施設レベル合計 50 |
| tycoon | タイクーンの風格 | 施設レベル合計 150 |
| maxFeeding | えさ場の極み | えさ場 Lv100(最大) |
| maxSignboard | 広告王 | 看板 Lv12(最大) |
| firstPig | はじめまして、ぶた | 通算捕獲 1回 |
| pigHoarder | 捕獲マニア | 通算捕獲 30回 |
| pigFriends | 豚と友達 | 図鑑 6種 |
| pigMaster | 図鑑コンプリート | 図鑑 12種 |
| firstPrestige | はじめての転生 | 転生 1回(フェーズ7で追加) |
| prestige5 | 輪廻のぶた | 転生 5回(フェーズ7で追加) |

## プレステージ(転生・フェーズ7で追加)

進行をリセットする代わりに「金の豚メダル」を獲得し、恒久的な生成ボーナスを得る周回要素。

### メダル計算式

```
獲得メダル = floor(√(今回の周回で稼いだ累計コイン ÷ 100,000))
```

- 転生ボタンは獲得メダルが1枚以上(周回コイン10万以上)で有効になる
- メダル1枚につき生成レート **+5%**(加算集計し、レート式の末尾に乗算で効く)

```
生成レート = (基本 + 加算施設) × 市場倍率 × (1 + 豚ボーナス) × (1 + 0.05 × メダル総数)
```

### リセットされるもの / 引き継がれるもの

| リセット | 引き継ぎ |
|---|---|
| コイン残高 | 豚図鑑(コレクションとボーナス) |
| 周回内の累計コイン | 実績・生涯累計コイン |
| 施設レベル(全施設Lv0) | メダル総数・転生回数 |
| 出現中の豚・オフラインレポート | |

- 転生は取り返しがつかないため、実行前に獲得予定メダル数を確認ダイアログで明示する
- 生涯累計コイン(実績用)と周回内累計コイン(メダル用)は別々に記録する

## 3Dワールド(フェーズ9で追加)

Robloxのタイクーンを参考にした、キャラクター操作型の3Dワールド。
数値・判定はすべて既存ロジックのまま、操作方法だけを置き換える。

### 操作

| 操作 | 入力 |
|---|---|
| キャラクター移動 | WASD または 矢印キー |
| 施設の強化 | 施設に近づく(約1.6ユニット以内)と表示されるプロンプトで Eキー、または施設をクリック |
| 豚の捕獲 | キャラクターを豚に接触させる(約1ユニット以内で自動捕獲)、または豚をクリック |

- 手動タップ(+1コイン)は3Dワールドでは廃止せず、地面クリックで発動する
- モバイルのタッチ移動(バーチャルパッド)はスコープ外

### ワールド構成

- 地面は牧場(柵つき)。4施設をワールドの四隅に、判別可能な3Dオブジェクトとして配置する
  - えさ場: 飼い葉桶、豚小屋: 屋根つき小屋、市場: 屋台、看板: 立て看板
- 各施設の足元に購入パッドを置き、**強化可能なら緑・コイン不足なら灰色**に変わる
- 施設はレベルに応じてわずかに大きくなる(視覚的な成長表現)
- 豚は既存の出現判定・座標(0〜1)をワールド中央エリアにマッピングして出現する
- カメラはキャラクター追従の三人称視点(固定オフセット・自由カメラなし)

## ワールド拡張(フェーズ10で追加)

### コイン山(手動収集の置き換え)

- フィールドのランダムな位置にコイン山が出現し、**キャラクターが接触すると回収**できる
- 回収額 = **現在の生成レート × 8秒分**(放置に対する能動プレイのご褒美)
- 回収から**20秒後**に別のランダムな位置へ再出現する
- 一時状態であり、セーブには保存しない(リロードで再出現判定からやり直し)
- ヘッダーの「タップで+1」ボタンと地面クリックの手動タップは廃止

### 飼育場(捕獲した豚の管理)

- ワールド左手前に柵付きの飼育場を設置する
- **図鑑に登録済みの種類ごとに1匹**、その種の色の豚が飼育場内を歩き回る(演出はUI層)
- 入口の看板に近づくと、ビューポート内オーバーレイで図鑑(捕獲状況・ボーナス)が表示される
- 離れるとオーバーレイは自動で閉じる。DOM下部の図鑑パネルは撤去する

### 転生の祠

- ワールド上部に金の豚像の祠を設置する
- 近づくと周回コイン・獲得予定メダルがオーバーレイ表示され、**Eキーで転生**
  (従来どおり確認ダイアログあり)。DOM下部の転生パネルは撤去する

### ワールド拡大・装飾

- 地面を 20×12 → **28×18** に拡大し、移動範囲・施設配置を再調整する
- 装飾オブジェクトを追加する: 木・池・岩・花・干し草ロール(すべてプリミティブ製・機能なし)

## MVPスコープ外(今回やらないこと)

- **プレステージ/周回要素**: バランス設計が別次元で難しく、まずコアループの手触りを確認したいため
- **実績システム**: コレクション(豚図鑑)が実質的に実績の役割を兼ねるため
- **サウンド・BGM**: アセット調達が必要で、ゲーム性の検証に不要なため
- **複数資源(木材・宝石等)**: コイン1種で成立するかをまず検証するため
- **マルチプレイ・ランキング**: サーバーが必要になり技術スタックが変わるため
- **3D化(React Three Fiber)**: CLAUDE.mdの通り将来の拡張候補。ロジック層の分離のみ担保する
- **モバイルネイティブ対応**: ブラウザ(PC・スマホWeb)のレスポンシブ対応までとする
- **チュートリアル**: UIを自明にすることで代替する。必要性はフェーズ5で再評価
