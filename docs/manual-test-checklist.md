# 手動動作確認チェックリスト(フェーズ4)

`npm run dev` で起動し、ブラウザ(http://localhost:5173)で以下を確認する。
数値の初期値は `src/logic/constants.ts` を参照。

## 資源(コイン)

- [ ] 起動直後、コインが1秒ごとに +1 ずつ増える(基本レート1/秒)
- [ ] 「タップで +1」ボタンを押すとコインが即座に +1 される
- [ ] ヘッダーの「+N /秒」表示が施設レベルに応じて変わる

## 施設

- [ ] コインが10未満のとき、えさ場の強化ボタンが非活性になっている
- [ ] コインが10以上でえさ場を強化すると、コインが10減りLv.1になる
- [ ] 強化後、次のコストが上がっている(えさ場 Lv1→2 は 11)
- [ ] えさ場強化後、毎秒の増加量が +1 されている
- [ ] 市場を強化すると、加算ではなく全体レートの倍率が上がる
- [ ] 看板を強化すると、牧場の「出現率 N% / 30秒」表示が +5% される(上限80%)

## 豚の出現と捕獲

- [ ] 30秒間隔の判定で豚が牧場エリアに出現することがある(基本確率20%。数分待って1回も出なければ異常)
- [ ] 出現した豚を15秒以内にタップすると図鑑に登録され、牧場から消える
- [ ] 15秒放置すると豚が消える
- [ ] 捕獲済みの種を再度捕獲すると、コインが加算される(コモン=現在レートの30秒分)
- [ ] 図鑑の未発見枠は「❓ / ???」表示になっている
- [ ] 捕獲すると図鑑のカウント(N / 12)が増え、生成ボーナスがヘッダーに表示される

## オフライン収集

- [ ] タブを閉じて1分以上待ってから再度開くと、「おかえりなさい!」モーダルが出て離席分のコインが加算されている
- [ ] 10秒未満のリロードではモーダルが出ない(コインは加算される)
- [ ] (時間があれば)2時間以上放置すると「最大2時間分」の注記つきでクリップされる

## セーブ・リセット

- [ ] リロードしてもコイン・施設レベル・図鑑が保持されている(localStorage `batotycoon:save`)
- [ ] 「データをリセット」→確認ダイアログでOKすると初期状態に戻る
- [ ] リセットの確認ダイアログでキャンセルすると何も起きない

## 実績(フェーズ6)

- [ ] 起動から100コイン貯まると「はじめてのおこづかい」が解除され、トーストが約4秒表示される
- [ ] 施設を1回強化すると「はじめての強化」が解除される
- [ ] 実績パネルで解除済み(🏅・明色)と未解除(🔒・淡色)が区別表示される
- [ ] 実績解除後にリロードしても解除状態が保持されている
- [ ] 旧セーブ(実績導入前)を読み込むと、達成済み条件の実績がトーストなしで解除済みになっている
- [ ] データリセットで実績も全て未解除に戻る

## レイアウト

- [ ] モーダル表示中は背面が暗転し、ボタンで閉じられる
