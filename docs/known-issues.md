# 既知の課題・見送った改善

MVPとして意図的に見送った項目と、把握済みの制限事項。次の拡張フェーズの候補リストを兼ねる。

## ゲームデザイン

- **豚の抽選に天井(pity)がない**: エピック(5%)を60捕獲しても引けない不運が理論上あり得る。
  MVPでは仕様のシンプルさを優先して見送り。導入するなら「N回連続で新種なしなら次は未取得種を確定」等
- ~~施設が最大レベルに達した後の目標がない~~ → **フェーズ7の転生で解消済み**
- **手動タップが終盤ほぼ無意味**: +1固定で強化対象外(仕様どおり)。序盤専用の演出と割り切っている
- **転生後の周回が単調**: メダル以外の周回変化(新施設の解放等)がなく、2周目以降は同じ手順の繰り返し
- **実績はバッジのみで報酬がない**(意図的な仕様。報酬を付けるならバランスノート更新とセットで)

## 3Dワールド(フェーズ8〜9)

- **WebGL非対応環境のフォールバックなし**: 非対応ブラウザでは牧場エリアが表示されない。
  2D版(git履歴の `PigField.tsx`)への自動フォールバックは未実装
- **3Dチャンクが約830kB(minify後)**: three.js本体のサイズ。遅延読み込みで初期表示への影響は
  回避済み(メインバンドルは約170kB)だが、低速回線ではワールド表示までにラグがある
- **モバイル(タッチ)での移動手段がない**: 移動はキーボードのみ。バーチャルパッド未実装のため、
  スマホでは施設クリック・豚クリックでしか操作できない
- **キャラクターと施設・豚の衝突判定は距離ベースの簡易実装**: メッシュ同士の物理衝突はなく、
  施設をすり抜けて歩ける
- **転生してもキャラクター位置はそのまま**: 演出(スポーン地点に戻る等)はない
- **コイン山・豚が装飾や施設と重なって出現することがある**: 出現エリアは中央寄りに
  制限しているが、木・岩との重なりまでは回避していない(拾う・捕まえる操作は可能)
- **飼育場の豚は演出のみ**: 個体をクリックしても反応しない。種類ごとの詳細表示は
  看板の図鑑オーバーレイで代替している

## 技術的な制限

- **タブを開いたまま非アクティブにした場合、オフライン上限(2時間)が適用されない**:
  tickが差分計算で全額加算するため。リロード時のみ上限が効く。対処するなら
  visibilitychange で離席検知して applyOfflineProgress を通す
- **豚の出現判定はタブがアクティブな間のみ**(仕様どおりだが、上記と挙動が非対称)
- **セーブは localStorage 1スロットのみ**: エクスポート/インポート機能なし。
  ブラウザデータ削除でセーブが消える
- **React StrictMode(開発時)でオフライン精算が2回走る**: 2回目は経過0秒のため実害なし
- **コイン残高は浮動小数**: 表示は切り捨てで整合するが、厳密な整数管理はしていない。
  MAX_SAFE_INTEGER でのクリップのみ実装済み

## UI/UX

- **豚の出現が視覚のみで通知される**: 音・バイブなし(サウンドはスコープ外)。
  別タブ作業中に出現に気づけない
- **豚がフィールド内を「うろつく」動きは未実装**: 出現位置に固定+ゆれアニメーションのみ。
  要件の「うろつき」は簡略化した
- **アニメーション・エフェクトが最小限**: 捕獲時の演出、コイン加算のパーティクル等なし
- **多言語対応なし**(日本語のみ)

## テスト

- **UIコンポーネントの自動テストなし**: ロジック・ストア層のみユニットテスト対象
  (63件)。UIは docs/manual-test-checklist.md による手動確認
- **バランス回帰テストは貪欲プレイ前提**: 実プレイヤーの行動(看板優先など)との乖離は
  シミュレーションでは検証していない
