# バランスノート(フェーズ5)

数値パラメータ(`src/logic/constants.ts`)の根拠と、検討した代替値の記録。
再調整するときはまずこのファイルを読み、`src/logic/balanceSim.test.ts` の
回帰テストを併せて更新すること。

## 計測方法

「毎秒、コストあたりのレート上昇が最大の施設を買う」貪欲プレイをシミュレーションした
(豚のランダム要素は除く。実プレイヤーはこれより遅くなるので、以下は成長速度の上限値)。

| 経過時間 | レート(コイン/秒) | 施設レベル(えさ場/豚小屋/市場) |
|---|---|---|
| 1分 | 14 | 13 / 0 / 0 |
| 5分 | 204 | 35 / 20 / 5 |
| 10分 | 436 | 47 / 30 / 12 |
| 30分 | 893 | 62 / 45 / 21 |
| 60分 | 1,206 | 69 / 53 / 26 |

このカーブは `balanceSim.test.ts` で「5分で10倍以上」「30分で100〜3000/秒」として
回帰テスト化してある。

## 各数値の根拠

### 基本レート 1/秒・えさ場 初期コスト10

最初のアップグレードに10秒(タップ併用なら数秒)。「数秒〜数十秒で最初の強化」の
目安どおり。**代替検討**: 基本レート0.5/秒だと初回強化まで20秒かかり、
最初の1分の手持ち無沙汰が長すぎた。

### コスト成長率: えさ場・豚小屋 1.15 / 市場 1.25

1.15は約5レベルでコスト2倍(1.15^5≈2.01)になり、序盤は数秒〜数十秒間隔で
強化が続く。**代替検討**: 1.20(約3.8レベルで2倍)は5分時点でレートが約半分になり、
序盤から停滞感が出るため見送り。市場のみ1.25と重くしたのは、乗算効果
(+10%/Lv)が加算施設より本質的に強く、同じ成長率だと市場一択になるため。

### 施設の役割分担(主力の切り替わり)

シミュレーション上、序盤(〜1分)はえさ場のみ、2分前後から豚小屋、
5分前後から市場に投資が移る。「序盤・中盤・終盤で主力施設が切り替わる」を
この構成で満たしている(balanceSim「投資が分散」テストで担保)。

### 看板(出現率 +5%/Lv・最大Lv12・総コスト約9,900)

出現率20%→80%が上限。総コスト約9,900は5分時点のレート(約200/秒)なら1分弱の
収入で、収集を進めたいプレイヤーが中盤に一括投資できる価格帯。
上限80%は「30秒ごとの判定が確定にならない」ためのランダム性の保険。

### 豚の収集期間の期待値

レア度エピック(抽選5%・2種)がボトルネック。両エピックの入手に必要な捕獲数の
期待値は 1/0.025 + 1/0.025 − 1/0.05 = **60捕獲**。出現率80%なら30秒判定×80%で
平均37.5秒に1匹 → 約38分。序盤の看板未強化期間を含め、
**図鑑コンプリートまで active プレイで1〜1.5時間**を想定。MVPの規模として妥当と判断。
連続ハズレの救済(天井)は known-issues に見送りとして記録。

### 重複変換(コモン30秒/レア2分/エピック10分ぶんのレート)

レートに比例させることでゲーム進行度に関わらず「拾って損はない」額になる。
終盤(1,200/秒)のエピック重複は約72万コインで、市場Lv26の次コスト(約16万)を
上回りすぎない範囲。

### オフライン上限 2時間

「寝る前に閉じて朝開く」と大幅に差がつくのを防ぐ足切り。放置ゲームとしては
短めだが、MVPでは能動プレイ(豚捕獲)を主軸にしたいため意図的に短くしている。
不評ならこの1定数の変更で済む。

## 転生メダル(フェーズ7で追加)

### 計算式: 獲得メダル = floor(√(周回コイン ÷ 100,000))、1枚 = レート+5%

- **√を使う理由**: 周回コインに比例させると「長く粘るほど得」になりすぎて転生の決断が
  起きない。√なら周回を伸ばしたときの限界効用が下がり、「そろそろリセットした方が速い」
  という判断点が自然に生まれる
- **除数10万の根拠**: 貪欲プレイの累計コインは開始10分前後で10万に到達する
  (5分時点レート約200/秒)。初回転生の解放を「1プレイセッション内(10分前後)」に
  置くことで、機能に気づいてから試すまでが短くなる
- **+5%/枚の根拠**: 初回転生(1〜3枚)で+5〜15%。序盤10分の再走コスト
  (機会損失およそ数万コイン)を1周回で回収できる水準。**代替検討**: +2%/枚は
  初回転生の体感がほぼゼロで「損した」印象になるため見送り。+10%/枚は5〜6回の
  転生でレートが2倍近くなりコスト曲線(1.15)を追い越しすぎるため見送り
- 1時間フルプレイの周回(累計約260万)で√26 → 5枚 = +25%。周回時間に対して
  緩やかに逓減する設計

## 調整判断のまとめ(フェーズ5)

計測の結果、現行値はフェーズ1で狙ったペーシングを満たしており、**数値変更なし**とした。
根拠となるカーブを回帰テスト(`balanceSim.test.ts`)として固定したので、
今後の調整はテストのしきい値と本ノートをセットで更新する。
